EN

Write a C program that initializes an integer array with a set of predefined values. The program should then iterate through the array, count how many of these numbers are positive (greater than zero), and finally print the total count of positive numbers.

TR

Belirli önceden tanımlanmış değerlerle bir tamsayı dizisini başlatan bir C programı yazın. Program daha sonra dizi üzerinde gezinmeli, bu sayılardan kaç tanesinin pozitif (sıfırdan büyük) olduğunu saymalı ve son olarak pozitif sayıların toplam sayısını yazdırmalıdır.
