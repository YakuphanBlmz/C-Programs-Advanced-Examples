EN

Given an array of integers, write a C program to calculate the sum of all positive numbers within the array. A number is considered positive if it is greater than zero. If the array contains no positive numbers, the sum should be 0.

TR

Verilen bir tam sayı dizisindeki tüm pozitif sayıların toplamını hesaplayan bir C programı yazın. Bir sayı sıfırdan büyükse pozitif kabul edilir. Eğer dizide hiç pozitif sayı yoksa, toplam 0 olmalıdır.
