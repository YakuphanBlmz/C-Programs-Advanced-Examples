In this challenging problem, you are tasked with implementing a dynamic collection of integer sets in C. The core constraint is that you *must not* use `struct` or `typedef` keywords. This requires you to manage all related data (the collection of sets, individual set capacities, and current element counts) using raw pointers and dynamic memory allocation/deallocation directly. This problem heavily emphasizes `pointer to pointer` concepts and robust memory management practices, simulating complex data structures without the aid of higher-level abstractions. You will deal with multi-level pointers and dynamic resizing of both the primary collection and its constituent sets.

Your collection will be represented by three dynamically allocated arrays, managed by corresponding pointers. `int** sets` will point to an array of `int*`, where each `int*` in turn points to a dynamically allocated array representing an individual set of integers. Alongside this, you will maintain `int* set_capacities` to store the allocated memory capacity for each set (to avoid frequent reallocations), and `int* set_counts` to track the actual number of elements currently stored in each set. Additionally, global or passed-by-reference integer variables like `num_sets` (current number of sets in the collection) and `collection_capacity` (allocated capacity for the `sets`, `set_capacities`, and `set_counts` arrays) will be crucial for managing the overall collection's state.

You are required to implement the following functions, ensuring correct memory allocation, deallocation, and resizing using `malloc`, `realloc`, and `free`. Crucially, pay attention to the `int***` parameters, which are necessary to modify the primary `sets` pointer if the collection itself needs to be `realloc`ated, or if an individual set within the collection changes its memory address due to its own `realloc`. Furthermore, remember to handle potential `malloc` or `realloc` failures gracefully. The functions are:
1.  `void initialize_collection(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int initial_collection_capacity)`: Allocates initial memory for the collection's metadata arrays and sets their initial state.
2.  `void add_new_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int initial_set_capacity)`: Adds a new empty set to the collection, resizing the collection's metadata arrays if its capacity is reached.
3.  `void add_element_to_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int set_index, int value)`: Adds an element to the set at the specified `set_index`, resizing that individual set if its capacity is reached. This function must handle the possibility that the base address of `sets[set_index]` changes due to `realloc`.
4.  `void remove_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int set_index)`: Removes the set at `set_index`, freeing its memory, shifting subsequent sets and their metadata, and optionally shrinking the main collection's arrays.
5.  `void cleanup_collection(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr)`: Frees all dynamically allocated memory associated with the entire collection.

Bu zorlu problemde, C dilinde dinamik bir tamsayı kümeleri koleksiyonu uygulamanız istenmektedir. Temel kısıtlama, `struct` veya `typedef` anahtar kelimelerini *kesinlikle kullanmamanız* gerektiğidir. Bu durum, ilgili tüm verileri (kümelerin koleksiyonu, bireysel küme kapasiteleri ve mevcut eleman sayıları) ham işaretçiler ve doğrudan dinamik bellek tahsisi/serbest bırakılması ile yönetmenizi gerektirir. Bu problem, `işaretçinin işaretçisi` kavramlarını ve karmaşık veri yapılarını üst düzey soyutlamaların yardımı olmadan simüle ederek sağlam bellek yönetimini yoğun bir şekilde vurgulamaktadır. Hem ana koleksiyonun hem de onu oluşturan kümelerin dinamik olarak yeniden boyutlandırılması ve çok seviyeli işaretçilerle uğraşacaksınız.

Koleksiyonunuz, ilgili işaretçiler tarafından yönetilen üç dinamik olarak tahsis edilmiş dizi ile temsil edilecektir. `int** sets`, `int*` dizisine işaret edecek, bu `int*` dizisindeki her bir `int*` ise kendi içinde dinamik olarak tahsis edilmiş, bir tamsayı kümesini temsil eden bir diziye işaret edecektir. Bunun yanı sıra, her bir küme için tahsis edilmiş bellek kapasitesini (sık sık yeniden tahsisleri önlemek için) depolayan `int* set_capacities` ve her bir kümede şu anda depolanan gerçek eleman sayısını takip eden `int* set_counts` dizilerini sürdüreceksiniz. Ek olarak, `num_sets` (koleksiyondaki mevcut küme sayısı) ve `collection_capacity` ( `sets`, `set_capacities` ve `set_counts` dizileri için tahsis edilmiş kapasite) gibi genel veya referansla geçirilen tamsayı değişkenleri, genel koleksiyonun durumunu yönetmek için kritik olacaktır.

`malloc`, `realloc` ve `free` kullanarak doğru bellek tahsisi, serbest bırakılması ve yeniden boyutlandırmayı sağlayarak aşağıdaki fonksiyonları uygulamanız gerekmektedir. Özellikle, koleksiyonun kendisinin yeniden tahsis edilmesi gerektiğinde veya koleksiyon içindeki bireysel bir küme kendi yeniden tahsisi nedeniyle bellek adresini değiştirdiğinde, birincil `sets` işaretçisini değiştirmek için gerekli olan `int***` parametrelerine dikkat edin. Ayrıca, olası `malloc` veya `realloc` başarısızlıklarını zarif bir şekilde ele almayı unutmayın. Uygulanacak fonksiyonlar şunlardır:
1.  `void initialize_collection(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int initial_collection_capacity)`: Koleksiyonun meta veri dizileri için başlangıç belleğini tahsis eder ve başlangıç durumlarını ayarlar.
2.  `void add_new_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int initial_set_capacity)`: Koleksiyona yeni boş bir küme ekler, koleksiyonun kapasitesi dolduysa meta veri dizilerini yeniden boyutlandırır.
3.  `void add_element_to_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int set_index, int value)`: Belirtilen `set_index`'teki kümeye bir eleman ekler, kapasitesi dolduysa o bireysel kümeyi yeniden boyutlandırır. Bu fonksiyon, `realloc` nedeniyle `sets[set_index]`'in temel adresinin değişme olasılığını ele almalıdır.
4.  `void remove_set(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr, int set_index)`: `set_index`'teki kümeyi kaldırır, belleğini serbest bırakır, sonraki kümeleri ve meta verilerini kaydırır ve isteğe bağlı olarak ana koleksiyonun dizilerini küçültür.
5.  `void cleanup_collection(int*** sets_ptr, int** set_capacities_ptr, int** set_counts_ptr, int* num_sets_ptr, int* collection_capacity_ptr)`: Tüm koleksiyonla ilişkili dinamik olarak tahsis edilmiş tüm belleği serbest bırakır.
