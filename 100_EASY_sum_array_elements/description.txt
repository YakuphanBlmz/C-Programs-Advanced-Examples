EN

Write a C program that calculates the sum of all integer elements in a predefined array. The program should iterate through the array, add each element to a running total, and finally print the total sum to the console. The array size is fixed.

TR

Önceden tanımlanmış bir dizideki tüm tam sayı elemanlarının toplamını hesaplayan bir C programı yazın. Program, dizi üzerinde döngü yaparak her elemanı bir toplam değişkenine eklemeli ve son olarak toplamı ekrana yazdırmalıdır. Dizinin boyutu sabittir.
