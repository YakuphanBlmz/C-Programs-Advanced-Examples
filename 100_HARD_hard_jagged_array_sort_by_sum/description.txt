EN

In C programming, managing dynamic memory becomes significantly challenging when fundamental data structuring tools like `struct` and `typedef` are unavailable. This problem is designed to test your mastery of raw pointers, dynamic memory allocation (`malloc`, `free`), and pointer arithmetic in a scenario where you must implicitly manage metadata. Your task is to create and manipulate a dynamically allocated 'list' of dynamic integer arrays, often referred to as a jagged array, without the aid of custom data types.

The core challenge lies in how to store the size of each individual inner array. Since `struct` is forbidden, you cannot encapsulate the array pointer and its size together. Instead, you are required to implement a common C trick: each dynamically allocated inner array must dedicate its *first integer element* to store its own effective data length. This means if an inner array needs to hold `N` integers of data, you must allocate memory for `N+1` integers, where the element at index `0` stores `N`, and the actual data starts from index `1` up to `N`. This approach demands meticulous attention to pointer offsets and array indexing throughout the problem.

Your program must first dynamically allocate a main array of `int*` pointers, representing the 'list' of inner arrays. This main array should contain a variable number of pointers (e.g., 5 to 10). For each slot in this main array, you must then dynamically allocate an inner integer array. These inner arrays should have varying, random sizes (e.g., between 5 and 15 data elements). Populate each inner array with random integer values (0-99), starting from the second element (index 1), after storing its size at index 0. Finally, you must sort the main array of pointers such that the inner arrays are ordered in ascending order based on the *sum* of their data elements (excluding the size element at index 0). After printing the arrays before and after sorting, ensure all dynamically allocated memory is correctly freed.

TR

C programlamada, `struct` ve `typedef` gibi temel veri yapısı araçları kullanılamadığında dinamik bellek yönetimi önemli ölçüde zorlaşır. Bu problem, işaretçiler, dinamik bellek tahsisi (`malloc`, `free`) ve işaretçi aritmetiği üzerindeki ustalığınızı, meta verileri dolaylı olarak yönetmeniz gereken bir senaryoda test etmek için tasarlanmıştır. Göreviniz, özel veri tipleri kullanmadan, dinamik olarak ayrılmış tamsayı dizilerinin ('jagged array' olarak bilinen) dinamik bir 'listesini' oluşturmak ve üzerinde işlem yapmaktır.

Temel zorluk, her bir iç dizinin boyutunu nasıl saklayacağınızdadır. `struct` kullanımının yasak olması nedeniyle, dizi işaretçisini ve boyutunu birlikte kapsülleyemezsiniz. Bunun yerine, yaygın bir C hilesi uygulamanız gerekmektedir: her dinamik olarak ayrılmış iç dizi, kendi etkili veri uzunluğunu depolamak için *ilk tamsayı elemanını* ayırmalıdır. Bu, bir iç dizinin `N` adet tamsayı veri tutması gerekiyorsa, `N+1` tamsayı için bellek ayırmanız gerektiği anlamına gelir; burada `0` indeksindeki eleman `N` değerini saklar ve gerçek veriler `1` indeksinden `N`'e kadar başlar. Bu yaklaşım, problem boyunca işaretçi ofsetlerine ve dizi indekslemeye titiz bir dikkat gösterilmesini gerektirir.

Programınız ilk olarak, iç dizilerin 'listesini' temsil eden `int*` işaretçilerinden oluşan ana bir diziyi dinamik olarak ayırmalıdır. Bu ana dizi, değişken sayıda işaretçi (örneğin, 5 ila 10 arası) içermelidir. Bu ana dizideki her yuva için, daha sonra dinamik olarak bir iç tamsayı dizisi ayırmanız gerekir. Bu iç diziler, değişen, rastgele boyutlara (örneğin, 5 ila 15 veri elemanı arası) sahip olmalıdır. Her iç diziyi, boyutunu 0 indeksinde sakladıktan sonra, ikinci elemandan (indeks 1) başlayarak rastgele tamsayı değerleri (0-99 arası) ile doldurun. Son olarak, ana işaretçi dizisini, iç dizilerin veri elemanlarının (0 indeksindeki boyut elemanı hariç) toplamına göre artan sırada sıralayacak şekilde düzenlemelisiniz. Sıralamadan önce ve sonra dizileri yazdırdıktan sonra, dinamik olarak ayrılan tüm belleğin doğru bir şekilde serbest bırakıldığından emin olun.
