EN

This problem challenges your mastery of pointers and dynamic memory allocation in C by requiring you to manipulate a two-dimensional integer array (matrix) where both its rows and columns can be dynamically modified. You are strictly forbidden from using `struct`, `typedef`, or file I/O operations, meaning all memory management must be performed using raw pointers (`int**`, `int*`) and standard library functions like `malloc`, `realloc`, and `free`.

Your task is to implement a program that first allocates a dynamic `M x N` integer matrix. This matrix should then be initialized with sequential integer values to make its contents easily traceable. After initial setup and printing the matrix, you must perform two distinct memory-intensive operations: deleting a specified row and deleting a specified column.

For deleting a row, you will need to `free` the memory block associated with that specific row's data. Subsequently, all `int*` pointers in the main array pointing to rows *after* the deleted row must be shifted to fill the gap. Finally, the main array of `int*` pointers itself must be `realloc`ated to reflect the reduced number of rows. This operation requires careful pointer arithmetic and memory management to prevent leaks and ensure the matrix remains coherent.

The most challenging part involves deleting a specified column. Unlike row deletion, this requires iterating through *each* remaining row. For every row, you must shift its elements to fill the gap created by the deleted column and then `realloc` the memory block for that specific row to a smaller size. This nested dynamic memory manipulation, coupled with the need to manage array dimensions manually without helper structures, demands a deep understanding of how C handles memory and pointers. After each deletion operation, the modified matrix must be printed, and finally, all allocated memory must be correctly freed to avoid any memory leaks.

TR

Bu problem, C dilinde işaretçiler ve dinamik bellek yönetimi konusundaki ustalığınızı test ediyor. Göreviniz, satırları ve sütunları dinamik olarak değiştirilebilen iki boyutlu bir tamsayı dizisi (matris) üzerinde işlem yapmaktır. `struct`, `typedef` veya dosya G/Ç işlemleri kullanmanız kesinlikle yasaktır, bu da tüm bellek yönetiminin yalnızca ham işaretçiler (`int**`, `int*`) ve `malloc`, `realloc` ve `free` gibi standart kütüphane fonksiyonları kullanılarak yapılması gerektiği anlamına gelir.

Programınız öncelikle dinamik bir `M x N` tamsayı matrisi ayırmalıdır. Bu matris, içeriğini kolayca takip edebilmek için sıralı tamsayı değerleriyle başlatılmalıdır. Başlangıçtaki kurulum ve matrisin yazdırılmasının ardından, iki farklı bellek yoğun işlem gerçekleştirmelisiniz: belirli bir satırı silmek ve belirli bir sütunu silmek.

Bir satırı silmek için, o belirli satırın verileriyle ilişkili bellek bloğunu `free` etmeniz gerekecektir. Daha sonra, ana dizideki silinen satırdan *sonraki* satırları işaret eden tüm `int*` işaretçileri boşluğu dolduracak şekilde kaydırılmalıdır. Son olarak, `int*` işaretçilerinden oluşan ana dizi, azaltılmış satır sayısını yansıtacak şekilde `realloc` edilmelidir. Bu işlem, bellek sızıntılarını önlemek ve matrisin tutarlı kalmasını sağlamak için dikkatli işaretçi aritmetiği ve bellek yönetimi gerektirir.

En zor kısım, belirli bir sütunu silmektir. Satır silmenin aksine, bu işlem kalan *her bir* satırda döngü yapmayı gerektirir. Her satır için, silinen sütunun oluşturduğu boşluğu doldurmak üzere elemanları kaydırmalı ve ardından o belirli satırın bellek bloğunu daha küçük bir boyuta `realloc` etmelisiniz. Yardımcı yapılar olmadan dizi boyutlarını manuel olarak yönetme ihtiyacıyla birleşen bu iç içe dinamik bellek manipülasyonu, C'nin belleği ve işaretçileri nasıl işlediğine dair derin bir anlayış gerektirir. Her silme işleminden sonra, değiştirilmiş matris yazdırılmalı ve son olarak, bellek sızıntılarını önlemek için ayrılan tüm bellek doğru bir şekilde serbest bırakılmalıdır.
