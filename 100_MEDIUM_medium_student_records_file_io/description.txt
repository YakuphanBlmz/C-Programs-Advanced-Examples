EN

In this problem, you will implement a basic student record management system using C structures and file I/O operations. Your program will allow users to input student data, save it to a binary file, and then load this data back from the file to display it and calculate an average grade. This exercise focuses on combining data structuring with persistent storage, which is a fundamental concept in application development. The use of `struct` and `typedef` helps organize related data efficiently. 

You need to define a `Student` structure using `typedef`, containing fields for student ID (integer), name (character array), and grade (floating-point number). The program should first prompt the user to enter data for a fixed maximum number of students (e.g., 3-5 students), then write these records to a file named `students.dat` in binary mode using `fwrite`. Subsequently, it must read the data from `students.dat` using `fread`, display each student's information, and finally compute and print the average grade of all loaded students.

Crucially, your solution must not use any explicit pointer variables or dynamic memory allocation (e.g., `malloc`, `free`). All data storage, including the array of student records, should be handled using fixed-size arrays declared on the stack. Pay close attention to file handling best practices, such as checking for `fopen` errors and properly closing file streams to prevent data corruption or resource leaks.

TR

Bu problemde, C dilindeki `struct` yapıları ve dosya giriş/çıkış (file I/O) işlemleri kullanarak temel bir öğrenci kayıt yönetim sistemi uygulayacaksınız. Programınız, kullanıcıların öğrenci verilerini girmesine, bunları ikili bir dosyaya kaydetmesine ve daha sonra bu verileri dosyadan geri yükleyerek görüntülemesine ve ortalama notu hesaplamasına olanak tanıyacak. Bu alıştırma, veri yapılandırmasını kalıcı depolama ile birleştirmeye odaklanmaktadır; bu, uygulama geliştirmede temel bir konudur. `struct` ve `typedef` kullanımı, ilgili verileri verimli bir şekilde düzenlemeye yardımcı olur.

`typedef` kullanarak bir `Student` yapısı tanımlamanız gerekmektedir; bu yapı öğrenci ID'si (tam sayı), adı (karakter dizisi) ve notu (ondalıklı sayı) için alanlar içerecektir. Program önce kullanıcıdan sabit bir maksimum öğrenci sayısı (örneğin, 3-5 öğrenci) için veri girmesini istemeli, ardından bu kayıtları `students.dat` adlı bir dosyaya `fwrite` kullanarak ikili modda yazmalıdır. Daha sonra, `students.dat` dosyasından `fread` kullanarak verileri okumalı, her öğrencinin bilgilerini görüntülemeli ve son olarak yüklenen tüm öğrencilerin not ortalamasını hesaplayıp yazdırmalıdır.

Çözümünüzde kesinlikle açık işaretçi değişkenler veya dinamik bellek tahsisi (örneğin, `malloc`, `free`) kullanılmamalıdır. Öğrenci kayıtları dizisi de dahil olmak üzere tüm veri depolama, yığında tanımlanmış sabit boyutlu diziler kullanılarak yapılmalıdır. `fopen` hatalarını kontrol etmek ve dosya akışlarını düzgün bir şekilde kapatmak gibi dosya işleme en iyi uygulamalarına dikkat edin.
