EN

You are tasked with developing a simple inventory management system for a small shop. This system needs to store product information in a binary file, allowing shopkeepers to add new products and view existing ones. Each product should have a unique ID, a name, a quantity, and a price.

The program must define a structure for a `Product` that includes an integer for the ID, a character array for the name, an integer for the quantity, and a float for the price. Use `typedef` to create an alias for this structure. Your program should provide two main functionalities: adding a new product's details to the `inventory.bin` file and listing all products currently stored in the file.

Crucially, you must avoid using pointers or dynamic memory allocation (like `malloc` or `free`) anywhere in your solution. All product data, including names, must be handled using fixed-size arrays within the structure. File operations should be performed using standard C file I/O functions such as `fopen`, `fwrite`, `fread`, and `fclose`.

TR

Küçük bir mağaza için basit bir envanter yönetim sistemi geliştirmeniz isteniyor. Bu sistemin ürün bilgilerini ikili bir dosyada saklaması, mağaza sahiplerinin yeni ürünler eklemesine ve mevcut ürünleri görüntülemesine olanak tanıması gerekmektedir. Her ürünün benzersiz bir kimliği (ID), bir adı, bir miktarı ve bir fiyatı olmalıdır.

Program, bir ID için tam sayı, ad için karakter dizisi, miktar için tam sayı ve fiyat için ondalık sayı içeren bir `Product` yapısı tanımlamalıdır. Bu yapı için bir takma ad oluşturmak üzere `typedef` kullanın. Programınız iki ana işlevsellik sağlamalıdır: yeni bir ürünün ayrıntılarını `inventory.bin` dosyasına eklemek ve dosyada depolanan tüm ürünleri listelemek.

Çözümünüzde kesinlikle işaretçi veya dinamik bellek ayırma (örneğin `malloc` veya `free`) kullanmaktan kaçınmalısınız. Adlar da dahil olmak üzere tüm ürün verileri, yapı içindeki sabit boyutlu diziler kullanılarak işlenmelidir. Dosya işlemleri, `fopen`, `fwrite`, `fread` ve `fclose` gibi standart C dosya I/O işlevleri kullanılarak yapılmalıdır.
