EN

Write a C program that calculates the sum of all even numbers present in a given integer array. Assume the array contains 5 elements. The program should initialize the array with some values and then print the final sum of its even elements.

TR

Verilen bir tam sayı dizisindeki tüm çift sayıların toplamını hesaplayan bir C programı yazın. Dizinin 5 eleman içerdiğini varsayın. Program, diziyi bazı değerlerle başlatmalı ve ardından çift elemanlarının nihai toplamını ekrana yazdırmalıdır.
