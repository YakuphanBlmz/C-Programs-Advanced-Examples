EN

This problem challenges you to demonstrate advanced proficiency in C's pointer arithmetic and dynamic memory management, without the aid of higher-level constructs like structs. Your task is to construct and manipulate a complex "jagged" two-dimensional array entirely using `pointer to pointer` (`int**`) and `malloc`/`free`. This requires careful attention to memory allocation, initialization, traversal, and crucially, deallocation to prevent memory leaks.

You will first need to dynamically allocate an array of `N` integer pointers. Let's refer to this as the "row pointer array". Subsequently, for each `i`-th element in this "row pointer array" (where `i` ranges from `0` to `N-1`), you must dynamically allocate a separate array of `i+1` integers. This means the `0`-th row will have `1` integer, the `1`-st row will have `2` integers, and so on, up to the `(N-1)`-th row having `N` integers. Once these inner arrays are allocated, populate each element `[i][j]` with the value `(i + 1) * (j + 1)`. For this problem, assume `N` is a constant integer value (e.g., `N=5` for your solution).

After successfully building and populating this jagged array, your primary task is to calculate the sum of all elements that reside at an *even column index*. That is, you must iterate through all rows and their respective elements, adding `jagged_array[i][j]` to a running total only if `j % 2 == 0`. Finally, after computing the sum, you must meticulously deallocate *all* dynamically allocated memory blocks in the correct order to ensure no memory leaks occur. The program should then print the final calculated sum to the standard output.

TR

Bu problem, C dilinde işaretçi aritmetiği ve dinamik bellek yönetimi konularındaki ileri düzey yeterliliğinizi, struct gibi daha yüksek seviyeli yapıları kullanmadan göstermenizi amaçlamaktadır. Göreviniz, tamamen `işaretçinin işaretçisi` (`int**`) ve `malloc`/`free` kullanarak karmaşık, "düzensiz" (jagged) bir iki boyutlu dizi oluşturmak ve manipüle etmektir. Bu, bellek tahsisi, başlatma, gezinme ve en önemlisi bellek sızıntılarını önlemek için bellek serbest bırakma konularına dikkatli bir yaklaşım gerektirir.

İlk olarak, `N` adet `int` işaretçisi içeren dinamik bir dizi tahsis etmeniz gerekmektedir. Bunu "satır işaretçi dizisi" olarak adlandıralım. Daha sonra, bu "satır işaretçi dizisinin" her bir `i`-inci elemanı için (burada `i`, `0`'dan `N-1`'e kadar değişmektedir), `i+1` adet `int` içeren ayrı bir dizi dinamik olarak tahsis etmelisiniz. Bu, `0`-inci satırın `1` adet `int`, `1`-inci satırın `2` adet `int` ve bu şekilde devam ederek `(N-1)`-inci satırın `N` adet `int` içereceği anlamına gelir. Bu iç diziler tahsis edildikten sonra, her `[i][j]` elemanını `(i + 1) * (j + 1)` değeriyle doldurunuz. Bu problem için, `N`'in sabit bir tam sayı değeri olduğunu varsayınız (örneğin, çözümünüz için `N=5`).

Bu düzensiz diziyi başarıyla oluşturup doldurduktan sonra, ana göreviniz *çift sütun indeksinde* bulunan tüm elemanların toplamını hesaplamaktır. Yani, tüm satırları ve ilgili elemanlarını gezmeli ve `jagged_array[i][j]` elemanını yalnızca `j % 2 == 0` ise toplamınıza eklemelisiniz. Son olarak, toplamı hesapladıktan sonra, bellek sızıntısı olmamasını sağlamak için dinamik olarak tahsis edilmiş *tüm* bellek bloklarını doğru sırayla titizlikle serbest bırakmalısınız. Program, hesaplanan nihai toplamı standart çıktıya yazdırmalıdır.
