EN

This challenging problem requires you to master dynamic memory allocation, pointer-to-pointer concepts, and the intelligent use of `realloc` without relying on `struct` or `typedef`. You will implement a C program that manages a dynamically allocated "jagged" 2D array, where each row can have a different number of columns. The core task involves not just creating and populating this complex data structure, but also dynamically resizing specific rows based on their content.

Initially, your program must allocate a main array of pointers to integers. Let's call this `matrix`. For a given number of rows, `R`, the `matrix` will point to `R` distinct rows. Each row `i` (0-indexed) must then be dynamically allocated to hold `i+1` integer elements. After allocation, populate `matrix[i][j]` with the value `(i * 10) + j`. To manage these varying row lengths, you will also need to dynamically allocate and maintain a separate array, `row_sizes`, which will store the current number of columns for each row in `matrix`.

The most complex part of this problem is implementing a function, `transformMatrix`, that takes the `matrix`, `R`, `row_sizes` array, and an integer `threshold` as arguments. This function must iterate through each row of the `matrix`. For every row `i`, calculate the sum of its elements. If this sum exceeds the given `threshold`, you must dynamically resize that specific row using `realloc` to *double its current size*. The newly allocated space (from the original size up to the new doubled size) must be filled with the value `-1`. Crucially, after `reallocating`, you must update the corresponding entry in the `row_sizes` array to reflect the new, doubled size of row `i`. Finally, your program must demonstrate the initial and transformed `matrix` contents and ensure all dynamically allocated memory is properly freed to prevent memory leaks.

TR

Bu zorlu problem, `struct` veya `typedef` kullanmadan dinamik bellek tahsisini, işaretçinin işaretçisi kavramlarını ve `realloc`'un akıllıca kullanımını ustalıkla uygulamanızı gerektiriyor. Her satırın farklı sayıda sütuna sahip olabileceği, dinamik olarak ayrılmış "düzensiz" (jagged) bir 2D tam sayı dizisini yöneten bir C programı uygulayacaksınız. Temel görev, bu karmaşık veri yapısını oluşturup doldurmakla kalmayıp, aynı zamanda içeriğine göre belirli satırları dinamik olarak yeniden boyutlandırmayı içeriyor.

Başlangıçta, programınız ana işaretçi dizisini tahsis etmelidir. Buna `matrix` adını verelim. Belirli bir `R` satır sayısı için, `matrix` `R` farklı satıra işaret edecektir. Her `i` satırı (0-tabanlı), `i+1` adet tam sayı öğesi içerecek şekilde dinamik olarak tahsis edilmelidir. Tahsisten sonra, `matrix[i][j]` değerini `(i * 10) + j` ile doldurun. Bu değişen satır uzunluklarını yönetmek için, `matrix`'teki her satırın mevcut sütun sayısını depolayacak ayrı bir dinamik olarak ayrılmış `row_sizes` dizisi de bulundurmanız gerekecektir.

Bu problemin en karmaşık kısmı, `matrix`'i, `R`'yi, `row_sizes` dizisini ve bir `threshold` (eşik) tam sayısını argüman olarak alan bir `transformMatrix` fonksiyonu uygulamaktır. Bu fonksiyon, `matrix`'in her bir satırını dolaşmalıdır. Her `i` satırı için, elemanlarının toplamını hesaplayın. Eğer bu toplam verilen `threshold`'u aşarsa, o belirli satırı `realloc` kullanarak *mevcut boyutunun iki katına* dinamik olarak yeniden boyutlandırmalısınız. Yeni ayrılan alan (orijinal boyuttan yeni iki katına çıkmış boyuta kadar) `-1` değeriyle doldurulmalıdır. En önemlisi, yeniden tahsis işleminden sonra, `row_sizes` dizisindeki ilgili girdiyi, `i` satırının yeni, iki katına çıkmış boyutunu yansıtacak şekilde güncellemeniz gerekmektedir. Son olarak, programınız başlangıçtaki ve dönüştürülmüş `matrix` içeriğini göstermeli ve tüm dinamik olarak ayrılmış belleğin bellek sızıntılarını önlemek için düzgün bir şekilde serbest bırakıldığından emin olmalıdır.
