EN

This problem challenges your understanding of advanced pointer usage and dynamic memory management in C, specifically focusing on scenarios where traditional fixed-size arrays are insufficient. You are tasked with creating and managing a "jagged array"—an array of arrays where each inner array can have a different size. Crucially, both the number of inner arrays and the sizes of these inner arrays are determined at runtime.

Your primary goal is to implement a robust system using only raw pointers and dynamic memory allocation functions (`malloc`, `free`). Since `struct` and `typedef` are explicitly disallowed, you must manage the collection of variable-sized arrays using `int**` and explicitly track individual array lengths separately. This requires careful handling of pointer arithmetic and multiple levels of indirection. You will allocate memory for an array of `int` pointers, and then for each `int` pointer, allocate memory for an actual array of integers.

You are required to implement four distinct functions: `allocateJaggedArray`, `fillJaggedArray`, `printJaggedArray`, and `freeJaggedArray`. The `main` function will demonstrate the usage of these functions. Pay close attention to error handling for `malloc` (checking for `NULL` returns) and ensuring all allocated memory is properly freed to prevent memory leaks. The correct order of deallocation is vital for nested dynamic allocations. If `malloc` fails at any point during the allocation of an inner array, you must deallocate all previously successfully allocated memory before returning `NULL`.

TR

Bu problem, C programlamada ileri düzey işaretçi kullanımı ve dinamik bellek yönetimi konusundaki anlayışınızı sınamak için tasarlanmıştır. Özellikle geleneksel sabit boyutlu dizilerin yetersiz kaldığı senaryolara odaklanılmıştır. Göreviniz, her iç dizinin farklı bir boyuta sahip olabileceği "jagged array" (düzensiz dizi) oluşturmak ve yönetmektir. Hem iç dizilerin sayısı hem de bu iç dizilerin boyutları çalışma zamanında belirlenecektir.

Ana hedefiniz, yalnızca ham işaretçiler ve dinamik bellek ayırma fonksiyonları (`malloc`, `free`) kullanarak sağlam bir sistem uygulamaktır. `struct` ve `typedef` kullanımı açıkça yasaklandığından, değişken boyutlu dizilerin koleksiyonunu `int**` kullanarak yönetmeli ve bireysel dizi uzunluklarını ayrı ayrı izlemelisiniz. Bu, işaretçi aritmetiği ve çoklu dolaylılık seviyelerinin dikkatli bir şekilde ele alınmasını gerektirir. Önce `int` işaretçilerinden oluşan bir dizi için bellek ayıracak, ardından her bir `int` işaretçisi için gerçek bir `int` dizisi için bellek ayıracaksınız.

Dört farklı fonksiyon uygulamanız istenmektedir: `allocateJaggedArray`, `fillJaggedArray`, `printJaggedArray` ve `freeJaggedArray`. `main` fonksiyonu bu fonksiyonların kullanımını gösterecektir. `malloc` için hata kontrolüne (`NULL` dönüşlerini kontrol etme) ve bellek sızıntılarını önlemek için tüm ayrılan belleğin düzgün bir şekilde boşaltılmasını sağlamaya özellikle dikkat edin. İç içe dinamik bellek ayırmalar için doğru bellek boşaltma sırası hayati öneme sahiptir. İç dizilerden herhangi birinin tahsisi sırasında `malloc` başarısız olursa, `NULL` döndürmeden önce daha önce başarılı bir şekilde ayrılan tüm belleği serbest bırakmanız gerekir.
