EN

You are tasked with developing a simple student record management system in C. This system should be able to store student information in a persistent manner using file I/O operations. Each student record will consist of a unique student ID, their name, and a grade.

Your program should first define a structure, `Student`, using `typedef`, to hold these three pieces of information. The student's name should be stored as a fixed-size character array. Subsequently, you need to implement functionality to perform two main operations: writing several predefined student records to a binary file named `students.dat`, and then reading all records from this file, displaying them on the console.

Finally, the program should prompt the user for a student ID, search for that student in the file, and display their details if found. If the student is not found after checking all records, an appropriate message should be displayed.

TR

C programlama dilinde basit bir öğrenci kayıt yönetim sistemi geliştirmeniz istenmektedir. Bu sistem, öğrenci bilgilerini dosya G/Ç işlemleri kullanarak kalıcı bir şekilde saklayabilmelidir. Her öğrenci kaydı, benzersiz bir öğrenci kimliği, adı ve notu içerecektir.

Programınız öncelikle bu üç bilgi parçasını tutacak `Student` adında bir yapı (`struct`) tanımlamalıdır. Öğrencinin adı, sabit boyutlu bir karakter dizisi olarak saklanmalıdır. Daha sonra, iki ana işlemi gerçekleştirecek bir işlevsellik uygulamanız gerekmektedir: önceden tanımlanmış birkaç öğrenci kaydını `students.dat` adında ikili bir dosyaya yazmak ve ardından bu dosyadan tüm kayıtları okuyarak konsolda görüntülemek.

Son olarak, program kullanıcıdan bir öğrenci kimliği istemeli, o öğrenciyi dosyada aramalı ve bulunursa detaylarını görüntülemelidir. Tüm kayıtlar kontrol edildikten sonra öğrenci bulunamazsa, uygun bir mesaj gösterilmelidir.
