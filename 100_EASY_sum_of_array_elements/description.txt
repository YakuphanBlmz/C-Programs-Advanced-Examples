EN

Write a C program that calculates the sum of all elements in a given integer array. The program should read 5 integer values into an array, then iterate through the array to find their total sum, and finally print the result.

TR

Verilen bir tam sayı dizisindeki tüm elemanların toplamını hesaplayan bir C programı yazın. Program, 5 tam sayı değerini bir diziye okumalı, ardından bu dizideki elemanların toplamını bulmak için diziyi dolaşmalı ve son olarak sonucu ekrana yazdırmalıdır.
