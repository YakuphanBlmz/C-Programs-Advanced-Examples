EN

Write a C program that calculates the sum of all integer elements in a given fixed-size array. For instance, if an array `int numbers[5] = {10, 20, 30, 40, 50};` is defined, the program should find and print its total sum.

TR

C dilinde, sabit boyutlu bir tamsayı dizisindeki tüm elemanların toplamını hesaplayan bir program yazın. Örneğin, `int numbers[5] = {10, 20, 30, 40, 50};` şeklinde tanımlanmış bir dizinin toplamını bulmalı ve ekrana yazdırmalıdır.
