EN

Write a C program that takes a positive integer as input and calculates the sum of its digits. For example, if the input is 123, the output should be 1 + 2 + 3 = 6.

TR

Pozitif bir tamsayıyı girdi olarak alan ve basamaklarının toplamını hesaplayan bir C programı yazın. Örneğin, girdi 123 ise, çıktı 1 + 2 + 3 = 6 olmalıdır.
