EN

Given an array of integers, write a C program to count how many of these integers are even. The program should iterate through the array and use the modulo operator to determine if each number is even. Finally, print the total count of even numbers found.

TR

Verilen bir tam sayı dizisindeki çift sayıları sayan bir C programı yazın. Program, dizi üzerinde dönmeli ve her sayının çift olup olmadığını anlamak için modulo operatörünü kullanmalıdır. Son olarak, bulunan çift sayıların toplam sayısını ekrana yazdırın.
